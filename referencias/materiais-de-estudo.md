# Materiais para continuar estudando Git e GitHub

Esta página reúne referências para revisar o conteúdo do minicurso e continuar praticando depois da aula. Estude com calma e atenção e absorva os conteúdos praticando :D

Nenhum vídeo ou site desta lista é necessário para acompanhar a aula.

## Por onde começar

Se você ainda está conhecendo Git e GitHub:

1. Leia [Sobre o Git](https://docs.github.com/pt/get-started/using-git/about-git);
2. Assista ao video do Galego no youtube > (https://www.youtube.com/watch?v=oi3eqnBcsJE&t=299s); Obs: Retirei muito da didática dele para trazer pro minicurso
3. Pratique em um projeto pessoal qualquer;
4. Use o Learn Git Branching para visualizar branches e merges.
5. Escolha uma das [sugestões de projetos](../projetos/ideias-para-praticar.md) e registre sua evolução em vários commits.

## Documentação oficial

Quando surgir uma dúvida sobre o funcionamento de um comando ou recurso, estas são as primeiras fontes que vale consultar.

### Git

- [Documentação do Git](https://git-scm.com/doc): referência dos comandos e opções disponíveis.
- [git-init](https://git-scm.com/docs/git-init): inicialização de repositórios.
- [git-status](https://git-scm.com/docs/git-status): estado dos arquivos e da área de preparação.
- [git-add](https://git-scm.com/docs/git-add): seleção das alterações que entrarão no próximo commit.
- [git-commit](https://git-scm.com/docs/git-commit): criação de commits.
- [git-branch](https://git-scm.com/docs/git-branch): criação, listagem e gerenciamento de branches.
- [git-switch](https://git-scm.com/docs/git-switch): troca e criação de branches.
- [git-merge](https://git-scm.com/docs/git-merge): integração de alterações de outra branch.
- [git-push](https://git-scm.com/docs/git-push): envio de commits para um repositório remoto.

Se adapte a ler documentações, é importante!

### GitHub

- [Sobre o Git](https://docs.github.com/pt/get-started/using-git/about-git): controle de versão, repositórios e relação entre Git e GitHub.
- [Olá, Mundo](https://docs.github.com/pt/get-started/using-github/hello-world): exercício introdutório sobre repositório, branch, commit e pull request.
- [Criar um repositório](https://docs.github.com/pt/repositories/creating-and-managing-repositories/creating-a-new-repository): criação e configuração inicial de um repositório no GitHub.
- [Adicionar um projeto local ao GitHub](https://docs.github.com/pt/migrations/importing-source-code/using-the-command-line-to-import-source-code/adding-locally-hosted-code-to-github): conexão entre um projeto que já está no computador e um repositório remoto.
- [Clonar um repositório](https://docs.github.com/pt/repositories/creating-and-managing-repositories/cloning-a-repository): criação de uma cópia local de um projeto remoto.
- [Sobre pull requests](https://docs.github.com/pt/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests): proposta, revisão e integração de alterações.
- [Gerenciar o README do perfil](https://docs.github.com/pt/account-and-profile/how-tos/profile-customization/managing-your-profile-readme): regras para exibir um README na página do perfil.
- [Trabalhar com GitHub no VS Code](https://code.visualstudio.com/docs/sourcecontrol/github): autenticação e recursos do GitHub dentro do editor. A documentação está em inglês.

## Ferramentas para visualizar branches e commits

### Learn Git Branching

[Abrir o Learn Git Branching em português](https://learngitbranching.js.org/?locale=pt_BR)

Simula um repositório no navegador e mostra graficamente o que acontece com commits, branches, merge e rebase. Comece pelas lições introdutórias. Alguns comandos fazem parte do simulador e não substituem a prática em um repositório real.

### Visualizing Git

[Abrir o Visualizing Git](https://git-school.github.io/visualizing-git/)

Permite digitar comandos e acompanhar a alteração do histórico em um diagrama. É útil para testar pequenas sequências de commits e branches sem mexer em um projeto importante.
